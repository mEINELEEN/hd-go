Разработан во время производственной практики специально для ГУ Минюста России по СПб и ЛО, на данный момент не используется, поэтому переведен на бесплатный хостинг -- https://helpdesk-l5ak.onrender.com/ 

Разработан продукт практики - сайт типа helpdesk для сотрудников. Основан на разделении ролей - пользователь и администратор. 
Пользователь регистрирует проблему, администратор - видит ее, затем выполняет и отмечает в системе, выполнил, отменил или что-то еще (оставил комментарий)
Хостинг бесплатный, поэтому каждые 15 минут неактива - сбрасывает БД, при перезапуске создаёт новую
